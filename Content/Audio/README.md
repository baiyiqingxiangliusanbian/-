# Runtime audio

公开源码仓库保留音频授权记录和导入说明；处理后的运行时 WAV/Unreal 音频资产随 [Release 下载包](https://github.com/baiyiqingxiangliusanbian/-/releases) 发布，不作为源代码提交的一部分。

这样可以把第三方素材授权边界、生成服务条款和可运行的实验包分开管理。需要从源码重新构建时，请按照 [`THIRD_PARTY_AUDIO.md`](THIRD_PARTY_AUDIO.md) 和 [`/Tools/AudioWorkbench/README.md`](../../Tools/AudioWorkbench/README.md) 准备本地音频资产；发布包已经包含可直接运行的处理后音频。
